# 🖥️ Redesign Concept: Vitrine de Produtos (Pichau)

Este projeto é um estudo de caso focado exclusivamente em **HTML5** e **CSS3**. O objetivo foi realizar um redesign visual da seção de listagem de produtos, priorizando a estética, a organização de componentes e a hierarquia visual em interfaces de e-commerce.

> **Nota:** Este é um **protótipo estático**. O foco principal deste repositório é demonstrar habilidades de estilização, layout e fidelidade visual, não possuindo funcionalidades de back-end ou interações complexas de sistemas de compra.

---

## 🎯 Desafio de Design

O foco foi resolver o problema de "poluição visual" em fundos escuros, onde muitas informações textuais acabam competindo entre si. 

### Principais ajustes realizados:
*   **Hierarquia de Informação:** O preço principal recebeu maior peso visual, enquanto informações secundárias (como parcelamento) ganharam tons de cinza para reduzir o ruído.
*   **Alinhamento de Grid:** Utilização de **CSS Grid** para garantir que os cards mantenham uma estrutura simétrica.
*   **Respiro (White Space):** Aplicação de margens e paddings estratégicos para que o nome do produto e o preço não pareçam "amontoados".
*   **Padronização:** Fixação de altura mínima nos títulos para que todos os botões de compra fiquem perfeitamente alinhados na base.

## 🛠️ Tecnologias e Conceitos Aplicados

*   **HTML5 Semântico:** Para uma estrutura limpa e acessível.
*   **CSS3 Avançado:** 
    *   Flexbox & CSS Grid.
    *   Pseudo-classes (`:hover`) para feedback visual.
    *   Box-model para controle preciso de espaçamentos.
    *   Variáveis de cores para consistência do Dark Mode.
